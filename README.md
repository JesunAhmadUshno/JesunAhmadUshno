## The question

How far can we trust the judge?

That is the question under this work. The research spine is evaluation reliability: whether the scores that decisions rest on deserve the trust placed in them. The roadmap below asks that question twenty-nine ways, in the open.

## The roadmap

## Measured results

Six studies, with the figures as published in their own repositories.

| Study | Result |
| :--- | :--- |
| [vector-systems-benchmark](https://github.com/JesunAhmadUshno/vector-systems-benchmark) | Three vector backends over 58,999 chunks. Unfiltered recall@10: FAISS 0.967, pgvector 0.978, Qdrant 1.000. Under a filter near 1 percent selectivity, FAISS falls to 0.413 and pgvector holds 1.000. |
| [experimentation-lab](https://github.com/JesunAhmadUshno/experimentation-lab) | Verdict: CONFIRMED. Question headlines reduce click-through: pooled odds ratio 0.8645, 95% CI 0.8335 to 0.8966, from a locked confirmatory run on the Upworthy archive. |
| [terraform-for-ai-infrastructure](https://github.com/JesunAhmadUshno/terraform-for-ai-infrastructure) | 13 of 13 plan equivalence across OpenTofu and Terraform. Drift detection recall 0.7037, against a naive baseline of 0.1667. |
| [langgraph-vs-native-study](https://github.com/JesunAhmadUshno/langgraph-vs-native-study) | A framework against a native loop on identical tasks. Pass rate 0.979 in both arms. 48 of 48 fault runs recovered exactly once in both arms. |
| [rag-eval-harness](https://github.com/JesunAhmadUshno/rag-eval-harness) | A RAG evaluation harness whose judge is checked against human labels. [Live dashboard](https://jesunahmadushno.github.io/rag-eval-harness). |
| [credit-risk-lab](https://github.com/JesunAhmadUshno/credit-risk-lab) | Credit risk modelling for fair access to credit in Canada. [Live dashboard](https://jesunahmadushno.github.io/credit-risk-lab). |
